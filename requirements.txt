# Pinned dependencies for the isolated transformer-sentiment work (transformer branch).

# GPU status (as of 2026-09-04): unconfirmed, not "no GPU". What's actually
# established is narrower: `nvidia-smi` is unavailable in the environments
# checked, and the existing Anaconda install's torch (2.13.0) is a CPU-only
# build reporting torch.cuda.is_available() == False. That does not rule out
# a GPU being present but undetected/unconfigured for Python.
#
# PyPI is the primary index; the PyTorch CPU wheel repo is an *extra* index
# (not a global override), so pandas/transformers/etc. still resolve from
# PyPI normally. torch itself is pinned to the explicit +cpu local build tag
# so it can never silently resolve a CUDA wheel regardless of which index
# serves it. Switching to a CUDA build requires explicit approval, and
# should only happen after GPU presence is actually confirmed on native
# Windows (e.g. Get-CimInstance Win32_VideoController), not just absence of
# nvidia-smi.
--index-url https://pypi.org/simple
--extra-index-url https://download.pytorch.org/whl/cpu
