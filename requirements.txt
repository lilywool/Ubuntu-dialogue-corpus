# Scope: this environment SCORES a small CSV fixture. It deliberately does
# NOT carry pandas 3.0.1 / pyarrow, and does NOT deserialize the source
# pickle. Source-deserialization compatibility is a separate concern with
# its own environment -- see requirements-extract.txt. Keeping them apart
# means the model runtime never inherits pins it only needs to read a
# 2,000-row CSV.
#
# GPU status (as of 2026-09-04): unconfirmed, not "no GPU". Established:
# nvidia-smi is unavailable in the environments checked, and the base
# Anaconda torch build is CPU-only with torch.cuda.is_available() == False.
# That does not rule out undetected/unconfigured hardware.
#
# PyPI is the primary index; the PyTorch CPU wheel repo is an *extra* index
# (not a global override), so pandas/transformers/etc. still resolve from
# PyPI normally. torch is pinned to the explicit +cpu local build tag so it
# can never silently resolve a CUDA wheel. Switching to a CUDA build needs
# explicit approval AND confirmed GPU presence.
